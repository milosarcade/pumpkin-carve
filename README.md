# Pumpkin Carve

Trace the dashed outline on each pumpkin with your knife before the time
runs out. Score 80% accuracy or better to win. There are five pumpkins, each
with less time than the last.

Play it: https://milosarcade.com/pumpkin-carve/

## How to play

- Drag with the mouse, or a finger, to carve.
- Cover the whole outline and stay on it: skipping parts or carving off the
  line lowers your score.
- Undo and Clear are there if you slip.

## Level editor

Draw your own pumpkin faces, save them under My pumpkins, and share them as
a level code that others can paste in to play.

## Files

- `index.html` is the whole game: HTML, CSS and JavaScript in one file.

Your own pumpkins are saved in the browser.
